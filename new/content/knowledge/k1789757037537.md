font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">矢量图形</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; font-variation-settings: inherit; font-language-override: inherit; font-size: 24px; color: rgb(0, 0, 0);">2. 分辨率</h2><img src="assets/images/content/84dfa9097de3e03dd5a8.png" alt=""></div><div><p class="wp-block-paragraph" style="margin: 0px 0px 20px; font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">图像分辨率</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; vertical-align: baseline; font-variant-numeric: inherit; font-variant-east-asian: inherit; font-variant-alternates: inherit; font-variant-position: inherit; font-variant-emoji: inherit; font-stretch: inherit; line-height: inherit; font-family: Jost, Arial, Helvetica, sans-serif; font-optical-sizing: inherit; font-size-adjust: inherit; font-kerning: inherit; font-feature-settings: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">图像分辨率是指单位图像线性尺寸中所包含的像素数目，通常以像素 / 英寸 (ppi) 为计量单位 . 打印尺寸相同的两幅图像，高分辨率的图像比低分辨率的图像所包含的像素多 . 例如：打印尺寸为 11 平方英寸的图像，如果分辨率为 72ppi，包含的像素数目为 5184(7272=5184). 如果分辨率为 300ppi，图像中包含的像素数目则为 90000. 高分辨率的图像在单位区域内使用更多的像素表示，打印时它们能够比低分辨率的图像重现更详细和更精细的颜色转变 。</p><h3 class="wp-block-heading" style="margin: 0px 0px 20px; font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">显示器分辨率</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">在进行图形图像处理时，色彩模式以建立好的描述和重现色彩的模型为基础，每一种模式都有它自己的特点和适用范围，用户可以按照制作要求来确定色彩模式，并且可以根据需要在不同的色彩模式之间转换 。 下面，介绍一些常用的色彩模式的概念 。</p><h3 class="wp-block-heading" style="margin: 0px 0px 20px; padding: 0px; border: 0px; vertical-align: baseline; font-variant-numeric: inherit; font-variant-east-asian: inherit; font-variant-alternates: inherit; font-variant-position: inherit; font-variant-emoji: inherit; font-stretch: inherit; line-height: 1.4; font-family: Jost, Arial, Helvetica, sans-serif; font-optical-sizing: inherit; font-size-adjust: inherit; font-kerning: inherit; font-feature-settings: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">RGB 色彩模式</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; vertical-align: baseline; font-variant-numeric: inherit; font-variant-east-asian: inherit; font-variant-alternates: inherit; font-variant-position: inherit; font-variant-emoji: inherit; font-stretch: inherit; line-height: inherit; font-family: Jost, Arial, Helvetica, sans-serif; font-optical-sizing: inherit; font-size-adjust: inherit; font-kerning: inherit; font-feature-settings: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">自然界中绝大部分的可见光谱可以用红 、 绿和蓝三色光按不同比例和强度的混合来表示 。RGB 分别代表着 3 种颜色：R 代表红色，G 代表绿色 、B 代表蓝色 。RGB 模型也称为加色模型，如图 5 所示 。RGB 模型通常用于光照 、 视频和屏幕图像编辑 。</p><h3 class="wp-block-heading" style="margin: 0px 0px 20px; padding: 0px; border: 0px; vertical-align: baseline; font-variant-numeric: inherit; font-variant-east-asian: inherit; font-variant-alternates: inherit; font-variant-position: inherit; font-variant-emoji: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">CMYK 色彩模式</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; vertical-align: baseline; font-variant-numeric: inherit; font-variant-east-asian: inherit; font-variant-alternates: inherit; font-variant-position: inherit; font-variant-emoji: inherit; font-stretch: inherit; line-height: inherit; font-family: Jost, Arial, Helvetica, sans-serif; font-optical-sizing: inherit; font-size-adjust: inherit; font-kerning: inherit; font-feature-settings: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">CMYK 色彩模式以打印油墨在纸张上的光线吸收特性为基础，图像中每个像素都是由靛青 (C)、 品红 (M)、 黄 (Y) 和黑 (K) 色按照不同的比例合成 。 每个像素的每种印刷油墨会被分配一个百分比值，最亮 ( 高光 ) 的颜色分配较低的印刷油墨颜色百分比值，较暗 ( 暗调 ) 的颜色分配较高的百分比值 。 例如，明亮的红色可能会包含 2% 青色 、93% 洋红 、90% 黄色和 0% 黑色 。 在 CMYK 图像中，当所有 4 种分量的值都是 0% 时，就会产生纯白色 。CMYK 色彩模式的图像中包含四个通道，如图 6 所示 。 我们所看见的图形是由这 4 个通道合成的效果 。</p><p class="wp-block-paragraph" style="margin: 0px 0px 20px; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">在制作用于印刷色打印的图像时，要使用 CMYK 色彩模式 。RGB 色彩模式的图像转换成 CMYK 色彩模式的图像会产生分色 。 如果您使用的图像素材为 RGB 色彩模式，最好在编辑完成后再转换为 CMYK 色彩模式 。</p><h3 class="wp-block-heading" style="margin: 0px 0px 20px; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">HSB 色彩模式是根据日常生活中人眼的视觉特征而制定的一套色彩模式，最接近于人类对色彩辨认的思考方式 。HSB 色彩模式以色相 (H)、 饱和度 (S) 和亮度 (B) 描述颜色的基本特征 。</p><h3 class="wp-block-heading" style="margin: 0px 0px 20px; font-variation-settings: inherit; font-language-override: inherit; font-size: 22px; color: rgb(0, 0, 0);">Lab 色彩模式</h3><p class="wp-block-paragraph" style="margin: 0px 0px 20px; padding: 0px; border: 0px; line-height: inherit; font-family: Jost, Arial, Helvetica, sans-serif; font-optical-sizing: inherit; font-size-adjust: inherit; font-kerning: inherit; font-feature-settings: inherit; font-variation-settings: inherit; font-language-override: inherit; font-size: 16px; color: rgb(0, 0, 0);">Lab 色彩模式由光度分量 (L) 和两个色度分量组成，这两个分量即 a 分量 ( 从绿到红 ) 和 b 分量 ( 从蓝到黄 )。Lab 色彩模式与设备无关，不管使用什么设备 ( 如显示器 、 打印机或扫描仪 ) 创建或输出图像，这种色彩模式产生的颜色都保持一致 。</p><h2 class="wp-block-heading" style="margin: 0px 0px 20px;
