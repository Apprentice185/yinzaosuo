  ## Start with the event details

  Before planning materials, gather the event theme, venue layout and dimensions, intended placement, attendee flow, and key dates. Requirements differ from one project to another; understanding site constraints and information priorities early can reduce avoidable revisions.

  ## Align the visual direction and information hierarchy

  Establish the event's visual direction, then decide which elements should extend to wayfinding and supporting materials. Individual pieces can use different layouts while retaining the necessary visual consistency. Confirm that key details such as dates, locations, and schedules remain accurate and easy to read.

  ## Select materials for the setting

  Based on the event flow and available space, consider whether any of these items are needed:

  - Event backdrops and display stands
  - Invitations, handbooks, and on-site guides
  - Gift packaging and branded stickers

  This list is a planning aid, not a requirement for every event. The actual items, quantities, dimensions, materials, and production methods should be confirmed against the venue requirements and project budget.

  ## Check details before production

  Before handing off files or arranging production, confirm final dimensions, placement, copy and brand information, required file formats, and delivery dates. If dimensions or site conditions are not yet known, confirm them before finalizing the related materials.

  ## Planning focus

  Effective materials planning starts with the event's goals and on-site use, coordinating visual communication, wayfinding, and practical production needs. The specific plan should be based on confirmed project information rather than assumed specifications or delivery commitments.

## 先梳理活动信息

规划物料前，先整理活动主题、场地平面与尺寸、预计使用位置、参会者动线及关键时间节点。不同项目的需求并不相同，先明确现场限制和信息优先级，可以减少后续反复调整。

## 统一视觉方向与信息层级

先确定活动的主视觉方向，再判断哪些内容需要延展到现场导视和宣传品。不同物料可以采用不同版式，但应保持必要的视觉识别一致，并确保时间、地点、流程等关键信息在各处准确易读。

## 按场景组合物料

可根据活动流程与空间，评估是否需要以下物料：

- 活动背景板与展架
- 邀请函、手册与现场导览
- 礼品包装及品牌贴纸

清单用于协助规划，不代表每场活动都需要全部项目。实际品类、数量、尺寸、材质和制作方式，应根据现场需求与项目预算确认。

## 制作前核对

在文件交付或安排制作前，建议逐项确认最终尺寸、摆放位置、文字与品牌信息、需要的文件格式，以及交付时间。若尺寸或现场条件尚未确定，应先确认相关信息，再定稿对应物料。

## 规划重点

好的物料规划从活动目标和现场使用出发，让视觉表达、导向信息和实际制作需求彼此协调。具体方案应以项目已确认的信息为准，不预设未经确认的规格或交付承诺。
