  ## 1. Raster and vector artwork: choose by content

  Raster images are made of pixels and work well for photographs, textures, and complex tonal imagery. Enlarging a raster image beyond the detail it contains can make edges look soft or jagged. Photoshop is one common raster editor.

  Vector artwork describes paths, curves, and shapes, making it useful for logos, icons, and other elements with crisp edges. Resizing a vector object generally avoids the loss of sharpness associated with enlarging a low-resolution raster image. Illustrator and CorelDRAW are common vector tools.

  Neither format is universally better. A print file often combines vector text and logos with raster photographs. A PDF can still contain raster images, so check the artwork itself rather than relying only on the file extension.

  ## 2. Resolution: consider the final size

  Image resolution describes the pixel detail in an image. For print, the effective resolution at the final placed size matters: when the same image is used larger, there are generally fewer pixels available per inch.

  A rough estimate is pixel width divided by final print width in inches. For example, a 3000-pixel-wide image placed at 10 inches is about 300 PPI. This is a calculation example, not a universal requirement for every job.

  Appropriate resolution depends on the finished size, viewing distance, print process, and image content. Enlarging an image through interpolation does not restore detail that was never captured. Confirm the requirements for the specific job with the print provider.

  ## 3. RGB and CMYK: different color workflows

  RGB combines red, green, and blue light to display color and is commonly used for screen content. CMYK uses cyan, magenta, yellow, and black inks and is commonly used for process-color printing. Their color ranges differ, so some colors can change during conversion.

  The final appearance is also affected by the color profile, paper, equipment, and production conditions. A screen preview alone cannot guarantee an exact printed match. If color is important to the project, confirm the required profile, file format, and whether a proof is needed before preparing the final files.

  ## Print file handoff checklist

  - Confirm the finished dimensions and aspect ratio, then check image sharpness at that size.
  - Check that raster images meet the project's requirements and vector elements render correctly.
  - Confirm the required color mode, profile, and file format.
  - Discuss spot colors, fonts, or other production requirements with the print provider.

  These basics can help identify common file issues, but output specifications vary by project. When in doubt, follow the production instructions supplied for the job.

## 1. 位图与矢量图：按内容选择

位图由像素组成，适合照片、纹理和复杂色调图像。放大位图时，如果像素不足，边缘可能变得模糊或出现锯齿。常见的位图编辑工具包括 Photoshop。

矢量图由路径、曲线和形状描述，适合标志、图标和文字图形等边缘清晰的元素。调整矢量对象的尺寸通常不会像放大低像素位图那样损失清晰度；常见工具包括 Illustrator 和 CorelDRAW。

两种图像没有绝对优劣，很多印刷文件会同时包含矢量文字、矢量标志和位图照片。即使文件格式是 PDF，其中的照片仍可能是位图，因此应检查实际图像内容，而不只看文件扩展名。

## 2. 分辨率：结合最终尺寸判断

图像分辨率描述图像包含的像素信息。印刷时，重要的是图像放到最终成品尺寸后的有效分辨率：同一张图片放得越大，每英寸可用的像素通常越少。

可以用像素尺寸除以最终打印尺寸（英寸）估算有效 PPI。例如，一张宽 3000 像素的图片用于 10 英寸宽的画面，有效分辨率约为 300 PPI。这个数值只是计算示例，不代表所有项目都必须达到同一标准。

合适的分辨率会受成品尺寸、观看距离、印制方式和图像内容影响。不要只为追求更高数字而盲目放大图片；插值放大不会凭空恢复原有细节。文件交付前，请按具体项目向印制方确认要求。

## 3. RGB 与 CMYK：显示与印刷的色彩方式

RGB 以红、绿、蓝光混合显示颜色，常用于屏幕内容。CMYK 以青、品红、黄、黑四色油墨表现颜色，常用于彩色印刷。两种色彩空间的表现范围不同，转换后某些颜色可能出现变化。

最终颜色还会受到色彩配置文件、纸张、设备和生产条件影响。因此，不能只靠屏幕预览保证印刷颜色完全一致。若项目对颜色有要求，可先向印制方确认色彩配置文件、交付格式及是否需要打样，再按确认后的流程处理文件。

## 印刷文件交付前的检查清单

- 确认成品尺寸与画面比例，检查图片放大后的清晰度。
- 核对位图是否满足项目要求，矢量对象是否正确显示。
- 确认色彩模式、配置文件和文件格式等交付规范。
- 将特殊颜色、字体或其他制作要求提前与印制方沟通。

这些基础知识有助于发现常见文件问题，但具体输出规范会因项目而异。遇到不确定的设置时，优先使用项目提供的制作说明。
